# About This Portfolio

A functional digital portfolio built with **React**, **TypeScript**, and **Vite**.

## Highlights

- **Home** — landing page with hero section
- **About** — personal introduction and background
- **Education** — academic history and qualifications
- **Professional Knowledge** — skills, technologies, and expertise
- **Pictures Gallery** — photo showcase
- **Video Gallery** — video showcase with YouTube embed
- **Blog** — articles and posts
- **Instant Messaging** — leave a message with auto-reply, powered by a Spring Boot backend

## Tech Stack

- **Framework:** React 19
- **Language:** TypeScript
- **Build Tool:** Vite
- **Routing:** React Router (HashRouter for static hosting)
- **Styling:** CSS Modules with centralized theme variables
- **Backend:** Spring Boot + H2 database (chat messages)
